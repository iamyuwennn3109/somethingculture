About Us

關於我們

用創意點燃品牌，用 IP 沉澱信任，用內容驅動增長

有點東西傳媒成立於香港，站在創意與商業的交匯點上。我們相信每一個品牌、每一位專業人士，都有其獨特的故事等待被講述 —— 而講述的方式，決定了它能被多少人記住。

團隊由資深營銷策略人、內容策劃與影像製作團隊組成，提供從品牌定位到個人 IP 孵化、從腳本策劃到拍攝執行的一站式服務。近年我們把重心放在一條更深的賽道上：幫助香港的專業代理人，通過微信視頻號，系統性地獲取內地高端客戶。

在這個注意力稀缺的時代，我們不做隨波逐流的跟隨者。我們做的是有態度、有深度、能帶來真實線索的內容。

「有點東西」不僅是公司的名字，
更是我們對每一個項目的承諾 ——
我們要做的，永遠比預期多一點。

主線二 · IP INCUBATION

讓香港專業代理人
被內地高端客戶先看見，再信任

在兩條主線中，個人 IP 孵化是近年增長最快、壁壘最深的一塊。我們為香港保險、地產、財富管理從業者運營微信視頻號 —— 從人設定位、腳本策劃、拍攝製作，到帳號運營與線索承接，搭建一條完整的內地高端客戶引流鏈路。

INSIGHT 01

需求在內地

高淨值家庭對港險、港房、跨境資產配置的需求持續上升。這類生意本質是「信人不信產品」—— 誰先被認識，誰就先被考慮。

INSIGHT 02

陣地在視頻號

視頻號是唯一能在微信生態內跑通「看內容 → 加微信 → 進私域 → 線下成交」的平台，鏈路最短，用戶畫像與高淨值人群高度重合。

INSIGHT 03

壁壘在人設

香港持牌身份、多年從業經歷，本身就是強信任背書。缺的從來不是資質，而是一個能把資質講成故事、並被持續看見的內容載體。

How We Work

五步交付 · 從 0 到獲客

01
人設定位

梳理從業資質、服務半徑與個人故事，確立「專家型」而非「銷售型」的內容人格，並統一視覺與語言調性。

02
選題與腳本

建立月度選題矩陣：政策解讀、案例複盤、港深生活、客戶問答。每條視頻配備完整分鏡腳本與開場鉤子。

03
拍攝製作

香港本地拍攝團隊上門，燈光收音專業配置。單條成片含字幕、封面、剪輯、配樂與合規複核。

04
帳號運營

視頻號 + 公眾號 + 朋友圈三端聯動。發布節奏、話題標籤、評論區互動與投流策略統一管理。

05
線索轉化

評論區與私信標準話術、企業微信承接 SOP、客戶分層標籤，配合月度轉化複盤報告持續優化。
